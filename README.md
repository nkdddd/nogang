# 우리집 학습플래너 (통합판)

학습플래너에 **천문장 트레이너 · MD 중학영단어 · 그래머 인사이드**를 합치고, 화면을 하루틀 형태(아래쪽 메뉴 + ✨ 빠른 계획)로 바꾼 버전입니다.

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 플래너 본체 (사이트 첫 화면). 아래쪽 메뉴 **할 일 · 일정 · 학습 · 기록**, ✨ 빠른 계획, ⋯ 메뉴 |
| `apps/sentence.html` | 천문장 트레이너 (문장방 · 문법방) |
| `apps/words.html` | MD 중학영단어 1800 (단어장 · 어근) |
| `apps/grammar.html` | 그래머 인사이드 트레이너 (레벨 1~3) |
| `assets/theme.css`, `assets/theme.js` | 공용 디자인 — 세 학습앱의 색·글꼴·카드·아래쪽 메뉴를 플래너와 같게 |
| `assets/family.js` | 공용 가족 연결 (이메일 신청 → 승인) |
| `assets/device.js` | 사용 환경(PC · 모바일) 판별 → `<html data-device>` 설정, 네 화면 공용 |
| `assets/push-config.js` · `firebase-messaging-sw.js` · `manifest.webmanifest` | 휴대폰 푸시(웹 푸시 키) · 푸시 수신 서비스 워커 · 홈 화면 설치 정보 |
| `assets/cards.js` · `assets/pokecards.js` · `assets/fx.js` | 🎴 포켓몬 카드팩 · 대결 (카드 목록 · 카드팩 뜯기 효과는 받아쓰기 프로그램과 공유) |
| `assets/gcal.js` | 📅 구글 캘린더 동기화 (Google Identity Services · Calendar API, 서버 없음) |
| `assets/ttobak.js` | 🌐 받아쓰기 프로그램(또박또박) 친구와 카드 대결 (그쪽 Firebase에 Google 계정으로 연결) |
| `tools/weekly-allowance.mjs` · `.github/workflows/weekly-allowance.yml` | 매주 토 18시 부모에게 용돈 알림 (GitHub Actions) |
| `assets/focus-sounds.js` | 포커스 타이머용 집중 사운드 (브라우저에서 직접 생성 · 음원 파일 없음) |

학습 탭에서 앱을 누르면 플래너 위에 전체 화면으로 열립니다. 같은 사이트·같은 Firebase 프로젝트라 **한 번 로그인하면 네 화면 모두 같은 계정**으로 동작합니다. 각 앱 파일은 단독으로 열어도 됩니다.

## 통합 데이터베이스 (Firebase 프로젝트 `splan-5512`)

```
users/{uid}                     프로필 {name, role: parent|child, email}      ← 네 앱 공용
payTerms/{자녀uid}              💰 용돈 기준 (1시간당 금액 · 상한 · 보너스 · 모의고사 점수) — 연결된 부모만 쓰기
familyRequests/{id}             가족 연결 신청 {fromUid, fromName, fromEmail, fromRole, toEmail, toUid, toName, status}
links/{부모uid}/children/{uid}  부모-자녀 연결 {name, requestId, addedAt}     ← 네 앱 공용

planner/{uid}/
  tasks/{id}                    학습 계획·실행 기록
  meta/categories, meta/settings  과목·교재·학습방법 / 목표·용돈 기준·학습앱 인정 설정(extApps)
  diary, daygoals, daytypes, payouts, weekcaps, certs
  apps/sentence                 천문장 학습 상태 + summary + dayLog{날짜: 문장 수}
  apps/words                    MD영단어 state(날짜별 log 포함) + summary
  focus/{날짜}                   포커스 타이머 기록 {min, sessions}
  allowanceSnap/{토요일}         그 주 용돈 계산 결과 (학생 플래너가 마감 전까지 갱신)
  focus/{날짜}.freeMin           과제 없이 쓴 포커스 타이머 시간 (용돈에 포함)
  notices/{토요일}               (부모) 용돈 정산서 · 읽음 여부
  pushTokens/{토큰}              (부모) 푸시 받을 기기
  meta/notify                    (부모) 알림 설정 {push, email, emailTo}
  apps/grammar                  그래머 인사이드 상태 + summary + dayLog{날짜: {sec, answered, correct, cards}}

giUsers/{uid}, giFriendRequests 그래머 인사이드 친구 랭킹용 공개 요약
```

- 플래너는 연결 코드 없이 `planner/{uid}/apps/*`를 직접 읽어 **날짜별 학습시간**으로 인정합니다
  (문장 1개 1.5분, 신규 단어 1분·복습 0.5분, 문법 집중 1분 = 1분 · 앱별 하루 30분, 합계 60분 상한 — ⋯ 메뉴 → 학습앱 인정 시간에서 조정).
- 인정 시간은 할 일 화면·학습 탭·이번 주 용돈 정산의 학습시간에 더해집니다. 부모가 자녀를 보고 있으면 그 자녀의 기록으로 계산합니다.
- Firestore 보안 규칙은 부모 계정이 연결된 자녀의 `planner/{자녀uid}/**`(특히 `apps/*`)를 읽을 수 있어야 합니다.

## 🖥️ PC · 📱 모바일 화면

- 자동 판별: 화면 너비 1024px 이상, 또는 860px 이상이면서 마우스를 쓰면 **PC 화면**, 그 밖에는 **모바일 화면**. 창 크기를 바꾸면 바로 바뀝니다.
- PC 화면: 왼쪽 사이드바 메뉴, 할 일 목록 + 오른쪽 요약, 주간 일정 7칸, 학습앱 카드 3칸, 타이머·기록 2칸, 설정·메뉴는 오른쪽 패널.
- 모바일 화면: 아래쪽 떠 있는 메뉴와 한 줄 레이아웃.
- 직접 고르기: ⋯ 메뉴 → **화면 보기**(자동 · PC · 모바일). 학습앱에도 같이 적용됩니다.

## 💰 주간 용돈 = ⏱ 시간 용돈 + 📚 학습앱 보너스 + 📝 모의고사 보너스

| 항목 | 계산 | 평소 최대 | 시험기간(🚀 부스터) |
|---|---|---|---|
| ⏱ 시간 용돈 | 공부한 시간 × 1시간당 금액(부모가 정함, 기본 1,000원) + **타이머로 잰 부분 +10%** (상한과 별도) | 10,000원 | **20,000원** (시간당 금액은 그대로 → 공부 시간이 두 배 필요) |
| 📚 학습앱 보너스 | 영단어 · 그래머 인사이드 · 천문장이 채점한 그 주 정답률 (주 30문항 이상) | 5,000원 | 5,000원 |
| 📝 모의고사 보너스 | 그 주 공부한 일반과목 범위로 본 모의고사 점수 (부모가 입력) | 5,000원 | 5,000원 |

- 정답률 → 보너스: **60% 이하 0원, 95% 이상 최대**, 그 사이는 비례 (100원 단위).
- **학습시간**: 할 일에 직접 적은 시간도 인정합니다. ▶ 타이머 · 포커스 타이머로 잰 시간은 그 몫에 **+10% 타이머 보너스**(부모가 % 조정, `payTerms.timerBonusRate`). 학습앱이 잰 시간은 부모가 포함/제외를 고릅니다. 하루 최대 인정은 🏫 등교일 4시간 · 🏖 자율학습일(주말·방학·직접 지정한 날) 8시간 (부모가 조정), 과제 1건당 계획의 3배 · 8시간 초과분은 제외.
- **모의고사**: 기록 → 용돈 정산 → "📝 이번 주 모의고사 범위"에서 그 주에 끝낸 과목별 범위를 보고 시험을 낸 뒤, 맞힌 개수/문항 수를 입력합니다 (`payTerms.mocks[주 토요일]`).
- 기준은 `payTerms/{자녀uid}`에 저장 (1시간당 금액, 평소/시험기간 상한, 보너스 최대, 정답률 기준, 최소 문항 수). 보안 규칙상 연결된 부모만 바꿀 수 있고 자녀 화면에는 보이기만 합니다.
- **부모 계정에서 조정** (자녀별): ⋯ → 설정 → **💰 용돈 기준 조정**(자녀 탭 선택) 또는 기록 → 용돈 정산 → 자녀 카드의 **⚙️ 조정**.
  ⏱ 1시간당 금액(₩500~₩3,000 버튼 · 직접 입력) · 💰 평소 주간 최대(₩5,000~₩30,000) · 🚀 시험기간 최대(₩10,000~₩50,000)를 바로 바꾸고,
  "평소 최대를 채우려면 한 주에 N시간" 안내가 함께 바뀌어요. 타이머 % · 하루 인정 시간 · 보너스는 '자세한 기준'. 자녀가 여럿이면 "다른 자녀에게도 똑같이".
- 천문장은 날짜별 채점(`dayStat`)을 저장해 주간 정답률을 계산합니다.
- 지급할 때 금액을 직접 고칠 수 있습니다. 계획 완료 · 학습일 · 복습은 참고 지표로만 보여 줍니다.

## 상단 용돈 바 · 주간 등급

- **용돈 바(모든 화면 상단 고정)**: 이번 주 용돈 ₩ · 오늘 번 금액 · 마감(D-day) · 시간/학습앱/모의고사 구성. 누르면 용돈 정산.
  부모 화면에서는 자녀별 이번 주 금액(자녀 기기의 `allowanceSnap`)을 보여 줍니다.
- **학습앱 위 실시간 바**: 천문장 · 영단어 · 문법이 채점할 때마다 `postMessage({type:"nogang-answer"})`를 보내고,
  플래너가 이번 주 정답률 → 정답률 보너스 → 용돈을 바로 다시 계산해 `+₩ / −₩`로 보여 줍니다.
- **학습 탭**: 맨 위에 이번 주 학습앱 정답률 보너스(₩), 앱 카드에 오늘 정답 수 · 정답률. 오늘 아직 안 한 앱이 위로.
- **주간 등급**: 캐릭터 대신 브론즈 → 실버 → 골드 → 플래티넘 → 다이아(Lv1~10) 배지. 주간 XP(완료 1개 20 · 공부 1분 1)로 정해지고 일요일마다 새로 시작. 대결 순위에도 쓰여요.

## 할 일 화면 (간결 모드)

- **일정 탭(주간 · 월간)**: 구글 캘린더처럼 일정을 누르면 상세 카드(수정 · 삭제 · 완료), 월간에서 날짜를 누르면 그날 일정 목록.
  삭제할 때 반복 일정이면 **이 일정만 / 이 일정 및 이후 일정 모두**를 고른 뒤 삭제 또는 취소. 반복 생성 시 `series` 묶음 id를 저장하고,
  예전 항목은 과목 · 교재 · 내용 · 방법 · 시간이 같은 이후 일정으로 판단합니다. 완료한 기록은 '이후 모두'에서도 남깁니다.
- **할 일 추가**: 과목 · 무엇을 · 시간(20/30/45/60/90분) · 날짜(오늘/내일)만. 교재 · 방법 · 반복 · 메모 · 템플릿은 "더 설정".
- **시간 인정 완화**: 계획·복기 점수로 시간을 깎지 않음, 늦게 체크해도 100% (일주일 안), 범위를 안 적어도 경고 없음. 이상치(계획의 3배 · 1건 8시간 · 하루 최대)만 걸러냄.

- 맨 위: 오늘 공부 시간 / 목표 · 완료 수 + **다음 할 일 1개**(▶ 타이머 · 완료).
- 할 일 카드: 과목 · 교재 · 방법 · 계획 시간 + [▶ 타이머] [완료]. **완료는 한 번 탭** — 타이머 시간 → 적어 둔 시간 → 계획 시간 순으로 기록.
  실제 시간 · 점수 · 메모 · 수정/복사/삭제는 "기록 · 메모 ▾"를 눌러 펼칩니다. 메모를 적으면 복기 10/10.
- **학습앱 할 일**(교재 · 단원 이름에 영단어/MD 중학 · 그래머/문법 · 천문장): 타이머 대신 **"영단어에서 학습 ›"** 버튼.
  누르면 앱이 해당 위치로 바로 열립니다 — 영단어 `Day N`, 그래머 `Ch.N`/단원 이름, 천문장 오늘 학습 (`apps/*.html#go={...}`).
  돌아왔을 때 앱 기록이 늘었으면 완료 여부를 묻고, 이런 할 일은 `appLinked`로 표시해 **앱이 잰 시간으로만** 용돈에 넣습니다(이중 계산 방지).
- 정리한 것: 칭찬 도장 · 별점 · 어제 vs 오늘 · 칭찬 문구 카드 · 이행률 도넛 · 계획/실제 카드 · 주간 목표 카드(상단 용돈 바가 대신).

## ✅ 완료할 때 학습 내용 · ⭐ 별점
- 할 일을 계획할 때 **공부할 내용**(예: 3단원 p.42-58)을 적어 두면, 완료를 누를 때 **계획 대비 얼마나 했는지 ⭐0~5**만 줘요 (`doneStars`).
- 미리 안 적었으면 완료를 누를 때 **공부한 내용을 적고**, **⭐이행**(`doneStars`) · **⭐이해도**(`underStars`)를 줘야 완료돼요 (`contentAfter:true`).
- 부모가 자녀 플래너에서 대신 체크하면 별점 없이 완료돼요. 별점은 할 일 카드 · 용돈 정산의 학습 목록에 보여요.

## 💌 용돈 요청 (이번 주 학습한 내용과 함께)
- 자녀: 기록 → 💰 용돈 정산에 **📒 이번 주 학습한 내용**(날짜별 과목 · 내용 · 시간 · 이행/이해 별점, 평균 이행)이 보이고, **💌 이번 주 용돈 요청하기**로 요청 (`planner/{자녀uid}/payRequests/{주 토요일}`).
- 부모: 앱을 열면 "💌 ○○이 용돈을 요청했어요" 알림, 기록 탭 맨 위 요청 카드 → 그 주 용돈 정산으로. 정산 카드에 요청 표시와 학습한 내용이 펼쳐져 있고, 지급하면 요청이 '지급 완료'로 바뀌어요.

## 📅 구글 캘린더 동기화
- 설정 → **📅 구글 캘린더 → ＋ 연결할 구글 이메일 추가** → 이메일 입력 → 그 계정으로 구글 로그인 (보고 있는 플래너 기준: 내 플래너 또는 부모가 연 자녀 플래너).
  여러 이메일(엄마 · 아이 …)을 하나씩 추가할 수 있고, 이메일마다 학습플래너 캘린더가 생겨요. 로그인한 계정이 입력한 이메일과 다르면 물어봐요. 목록에서 다시 연결 · 맞추기 · 빼기.
- **플래너 → 구글**: 'OO 학습플래너' 캘린더를 새로 만들고, 할 일을 종일 일정으로 넣어요 (제목 `📘 과목 · 공부할 내용 (30분)`, 완료하면 `✅` · 초록색, 설명에 교재 · 방법 · 별점 · 메모).
